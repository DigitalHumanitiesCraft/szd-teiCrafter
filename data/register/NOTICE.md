# NOTICE: szd-persons.json

`szd-persons.json` is derived from the person index of Stefan Zweig Digital (GAMS object
`o:szd.personen`, https://gams.uni-graz.at/o:szd.personen/TEI_SOURCE), published by the
Literaturarchiv Salzburg with the Austrian Centre for Digital Humanities, University of Graz.

- Content per entry: index identifier (`SZDPER.n`), name, GND identifier where the index has
  one, life dates, and a folded search field built from name and name variants.
- Built by `node tools/build-person-index.mjs`; the retrieval date is recorded in the file.
