# Import record: working set from szd-htr

The TEI documents listed here were copied byte-exact from the szd-htr pipeline by
`tools/import-working-set.mjs`, following the selection in `tools/working-set.json`.
From their import on they are maintained in this repository (ADR-010); szd-htr receives
no corrections back.

- Source repository: https://github.com/chpollin/szd-htr-ocr-pipeline.git, path `results/<collection>/<objectId>.tei.xml`.
- Provenance: the szd-htr commit the script read from, whether the file is tracked in
  git there (most TEI results are gitignored and regenerated by the pipeline), the
  import date and the SHA-256 of the copied source bytes, which identifies the
  uncorrected original.
- Content: machine-generated TEI (Page-JSON transcribed by an LLM, converted to TEI),
  structure and transcription unreviewed. The raw HTR markers `~~…~~`, `[?]`, `{…}`
  and `[...]` are still plain text.
- Facsimiles are not copied; the editor loads them from the GAMS IIIF manifest
  `https://gams.uni-graz.at/o:szd.NNNN/sdef:IIIF/getManifest`.
