        Eine Collection einrichten

        Der Editor ist eine statische Seite ohne Server, daher entsteht eine Collection im Repository und erscheint nach dem nächsten Laden hier.

        1. Einen Ordner unter data/ anlegen, etwa data/tagebuecher/.
        2. In js/source.js unter collections einen Eintrag mit key (dem Ordnernamen), label und description ergänzen.
        3. Die Dokumente in tools/working-set.json eintragen und mit node tools/import-working-set.mjs importieren.
        4. Den Index mit node tools/build-document-index.mjs neu bauen und alles committen.
